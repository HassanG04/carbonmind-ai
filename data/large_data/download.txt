# CarbonMind data sources not mirrored into Git
#
# Reasons include large archives, model artifacts, API-only sources, missing
# reuse terms, private row-level data, or licensed/restricted inputs. Download
# into an approved local or secure dataset store only after checking terms.

[computer_vision]
YOLO pretrained weights and documentation
https://docs.ultralytics.com/models/
Reason: model artifact; keep weights outside the Git data registry and pin the exact model/license when an experiment starts.

COCO 2017
https://cocodataset.org/#download
Reason: large image/annotation archive; use a task-specific subset or secure dataset cache.

Open Images V7
https://storage.googleapis.com/openimages/web/index.html
Reason: very large image and annotation collection; use category subsets and document the selected release.

SUN RGB-D
https://rgbd.cs.princeton.edu/
Reason: large RGB/depth research dataset; download only for an approved depth experiment.

[lca_and_products]
Boavizta device-impact API
https://doc.api.boavizta.org/
Reason: API documentation, not a file to vendor into the repository; external calls require explicit authorization.

ÖKOBAUDAT building-material downloads
https://oekobaudat.de/en/service/downloads.html
Reason: release archives and CSV exports are large and format/license/boundary review is still required.

IPCC Emissions Factor Database
https://www.ipcc-nggip.iges.or.jp/EFDB/find_ef_main.php
Reason: searchable factor database; retrieve and version individual factors only after scientific review.

[electricity_and_weather]
Ember yearly global electricity release
https://files.ember-energy.org/public-downloads/generation/outputs/release_generation_yearly_global.csv
Reason: full current release was about 16 MB at retrieval; only filtered Egypt rows are stored locally in ../electricity/ember-egypt-yearly.csv.

NASA POWER hourly weather API
https://power.larc.nasa.gov/docs/services/api/temporal/hourly/
Reason: API source; query by approved site/time window and retain request parameters and retrieval metadata.

Haynes 2024 — UK community questionnaire
https://doi.org/10.3390/su16219211
