# Electricity data

`ember-egypt-yearly.csv` is a filtered copy of the Egypt rows from Ember's yearly global electricity release. It is intended for electricity-context exploration and forecast covariates.

It must not silently replace a verified location-based or market-based Scope 2 factor. Any future factor use requires a versioned factor record with geography, reporting period, methodology, unit, source and GWP basis.

Source: https://ember-energy.org/data/yearly-electricity-data/
